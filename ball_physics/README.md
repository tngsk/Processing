# 等加速度直線運動シミュレーション

このProcessingスケッチは、高校物理で学ぶ等加速度直線運動の公式を用いてボールの動きをシミュレーションするプログラムです。

## 物理の公式

### 速度の公式
v = v₀ + at

- v: 時間tにおける速度
- v₀: 初速度
- a: 加速度
- t: 時間

### 位置の公式
x = x₀ + v₀t + (1/2)at²

- x: 時間tにおける位置
- x₀: 初期位置
- v₀: 初速度
- a: 加速度
- t: 時間

## プログラムの特徴

- 等加速度直線運動の公式を使ってボールの位置を計算
- x方向とy方向の運動を独立に計算
- y方向には重力加速度を設定
- 画面の端でボールが反射
- マウスクリックでボールの初期位置と初速度をリセット
- スペースキーで一時停止

## 使い方

1. Processingで`ball_motion.pde`を開きます
2. 実行ボタンをクリックしてシミュレーションを開始します
3. マウスでクリックすると、クリックした位置にボールが移動し、ランダムな初速度で動き始めます
4. スペースキーを押すとシミュレーションを一時停止/再開できます

## パラメータの調整

プログラム上部の以下の値を変更することで、シミュレーションの挙動を調整できます：

- `x0`, `y0`: ボールの初期位置
- `v0x`, `v0y`: ボールの初速度
- `ax`, `ay`: ボールの加速度（`ay`は重力加速度）
- `ballRadius`: ボールの大きさ
- `dt`: シミュレーションの時間ステップ
