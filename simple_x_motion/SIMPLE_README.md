# 等加速度直線運動シミュレーション（X軸のみ）

このProcessingスケッチは、高校物理で学ぶ等加速度直線運動の公式をX軸方向のみで表現したシンプルなシミュレーションです。

## 物理の公式

### 速度の公式
v = v₀ + at

- v: 時間tにおける速度
- v₀: 初速度
- a: 加速度
- t: 時間

### 位置の公式
x = x₀ + v₀t + (1/2)at²

- x: 時間tにおける位置
- x₀: 初期位置
- v₀: 初速度
- a: 加速度
- t: 時間

## プログラムの特徴

- X軸方向のみの等加速度直線運動をシミュレーション
- 位置-時間グラフをリアルタイム表示
- 軌跡上にボールが運動する様子を視覚化
- パラメータ（初速度、加速度）をインタラクティブに変更可能

## 操作方法

1. `simple_x_motion.pde`をProcessingで開いて実行
2. マウスクリック：ボールの初期位置を設定し、ランダムな初速度と加速度で再スタート
3. スペースキー：シミュレーションの一時停止/再開
4. 'r'キー：パラメータを初期値にリセット
5. 'a'/'A'キー：加速度を減少/増加
6. 'v'/'V'キー：初速度を減少/増加

## 学習ポイント

1. 等加速度直線運動では、位置は時間の2次関数になる
2. 加速度が正のとき、位置-時間グラフは上に凸の放物線になる
3. 加速度が負のとき、位置-時間グラフは下に凸の放物線になる
4. 加速度が0のとき、位置-時間グラフは直線になる（等速直線運動）

## 重要なパラメータ

- `x0`: 初期位置
- `v0`: 初速度
- `a`: 加速度
- `t`: 経過時間
- `dt`: シミュレーションの時間ステップ

このシミュレーションを通じて、等加速度直線運動の基本概念を視覚的に理解することができます。
